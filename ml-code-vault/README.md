# ⚡ ML Lab Experiments Vault

A clean, fast, and modern web repository for **B.Tech CSE Machine Learning Lab Experiments (1 to 8)**.

All experiments are displayed directly on a single page with **3 Dedicated 1-Click Copy Buttons**:
1. **📋 Copy Algorithm** (Step-by-step numbered manual procedure)
2. **💻 Copy Program** (Clean, executable Python code with Scikit-learn/NumPy/Matplotlib)
3. **📊 Copy Output** (Verified evaluation metrics, regression plots, classification reports, and test accuracies)

---

## 📚 Experiments Included

1. **Experiment 01: Simple Linear Regression** (`california_housing.csv`)
2. **Experiment 02: Linear vs Polynomial Regression** (`auto-mpg.csv`)
3. **Experiment 03: Linear, Ridge & Lasso Regression** (`Diabetes.csv`)
4. **Experiment 04: Logistic Regression MLE & MAP (L1/L2)** (`Breast_cancer_Wisconsin.csv`)
5. **Experiment 05: MLE & MAP Estimation of Multinomial Distribution** (`20 Newsgroups`)
6. **Experiment 06: Logistic Regression With vs Without Scaling** (`diabetes (2).csv`)
7. **Experiment 07: Implementation of Naive Bayes Classifier** (`20NewsGroups1.csv`)
8. **Experiment 08: K-Nearest Neighbors (k-NN) Algorithm** (`fashion-mnist`)
